Ausblick
========

Wenn Sie sich durch das gesamte "Einstieg"-Kapitel durchgearbeitet haben, haben Sie nun eine fertige Yii-Anwendung
erstellt. Dabei haben Sie gelernt, häufig benötigte Funktionen wie z. B. das Erfassen von Benutzerdaten mittels
HTML-Formularen, das Lesen von Daten aus einer Datenbank und deren seitenweise Darstellung umzusetzen. Sie wissen jetzt
auch, wie man mittels [Gii](https://www.yiiframework.com/extension/yiisoft/yii2-gii/doc/guide) automatisch Code
generieren kann. Die Verwendung von Gii zur Code-Generierung macht einen Großteil Ihres Webentwicklungsprozesses so
einfach wie das Ausfüllen einiger Formulare.

Dieser Abschnitt fasst die verfügbaren Yii-Ressourcen zusammen, die Ihnen helfen, bei der Verwendung des Frameworks
produktiver zu sein.

* Dokumentation
    - [Das umfassende Handbuch](https://www.yiiframework.com/doc-2.0/guide-README.html):
      Wie der Name vermuten lässt, definiert dieses Handbuch genau, wie Yii funktionieren soll, und bietet eine
      allgemeine Anleitung zur Verwendung von Yii. Es ist das wichtigste Yii-Tutorial, und Sie sollten es lesen, bevor
      Sie Yii-Code schreiben.
    - [Die Klassenreferenz](https://www.yiiframework.com/doc-2.0/index.html):
      Hier finden Sie die Dokumentation aller Klassen, die von Yii bereitgestellt werden. Sie kommt hauptsächlich dann
      zur Anwendung, wenn Sie beim Programmieren die Verwendung bestimmter Klassen, Methoden oder Eigenschaften
      verstehen möchten. Die Verwendung dieser Dokumentation empfiehlt sich erst, wenn Sie ein Kontextverständnis des
      gesamten Frameworks entwickelt haben.
    - [Die Wiki-Artikel](https://www.yiiframework.com/wiki/?tag=yii2):
      Die Wiki-Artikel wurden von Yii-Benutzern auf Basis ihrer eigenen Erfahrungen geschrieben. Die meisten dieser
      Artikel sind im Stile von "Kochrezepten" verfasst und demonstrieren damit exemplarisch die Lösung eines
      spezifischen Problems mittels Yii. Während die Qualität dieser Artikel unter Umständen die des Handbuchs nicht
      erreicht, sind sie insofern nützlich, als sie ein breiteres Themenspektrum abdecken und oftmals
      "Ready-to-use"-Lösungen anbieten.
    - [Bücher](https://www.yiiframework.com/books)
* [Erweiterungen](https://www.yiiframework.com/extensions/):
  Yii bietet eine Bibliothek mit tausenden Erweiterungen, die von Yii-Benutzern beigesteuert wurden und einfach in Ihre
  Anwendungen integriert werden können. Damit lässt sich Ihr Entwicklungsprozess weiter beschleunigen und vereinfachen.
